## 阶段 0 · PoC 验证

**目标**：清除所有 P0 级技术风险，确认方案可行。

**产出**：一个能"出声 + 有托盘 + 有媒体控制"的最小应用。

| 任务 | 验收 |
|---|---|
| gpui-kit 脚手架 | 三平台能编译出可运行窗口 |
| libmpv 集成 | 播放一个本地音频文件 |
| playwire 集成 | KDE 媒体中心显示卡片、暂停按钮有效 |
| `tray-icon` 集成 | 托盘图标显示、点击有响应 |
| `directories` 集成 | 三平台路径正确 |

**详见** [`05-PoC验证清单.md`](05-PoC验证清单.md)

**关键决策点**：
- playwire 是否采用（否则切 zbus 自研）
- libmpv 绑定选择

> ⚠️ **本阶段结束前不要开始 UI 开发** —— 若 gpui-kit 或 libmpv 不满足，方案需调整。

---

## 阶段 1 · 核心播放

**目标**：能搜索、能登录、能播放网易云音乐。

| 模块 | 内容 |
|---|---|
| **网络层** | HTTP 客户端、请求签名（WeApi/EApi 加密） |
| **认证** | 扫码登录 / Cookie 登录 |
| **API** | 搜索、歌曲详情、播放地址获取 |
| **播放控制** | 队列、播放/暂停、上下一首、seek、模式切换 |
| **音频引擎** | libmpv 封装（加载、播放、事件回调、设备选择） |
| **基础 UI** | 主窗口、播放条、搜索页、登录页 |
| **状态管理** | 播放状态流、订阅机制 |

**里程碑**：`能播放一首歌，并能在播放条上控制`

**技术重点**：
- 网络加密需对照 Melodia 实现重写，用其测试用例作验收
  （见 [`04-迁移规格.md § 5`](04-迁移规格.md#5-网络层规格)）
- 注意 RSA 模数的**修正值**（Melodia 源码有注释指出历史拼写错误）

## 阶段 2 · 平台集成

**目标**：具备原生桌面体验。

| 模块 | 内容 |
|---|---|
| **系统媒体控制** | MPRIS（Linux）/ SMTC（Windows）完整接入 |
| **托盘** | 图标、菜单、显示/隐藏窗口 |
| **窗口装饰** | 无边框窗口、自绘标题栏 |
| **单实例** | 重复启动唤起已有窗口 |
| **流式缓存** | 边播边缓存、缓存命中、淘汰 |
| **设置页** | 音质、缓存、主题 |

**里程碑**：`关闭窗口最小化到托盘；系统媒体键能控制播放`

**技术重点**：
- MPRIS 需对照 [`02-平台能力规格.md § 3.4`](02-平台能力规格.md) 的 8 条检查
- 托盘需在 **KDE Wayland** 下实测点击响应

## 阶段 3 · 功能完善

**目标**：功能对齐主流客户端。

| 模块 | 内容 |
|---|---|
| **音乐库** | 歌单、专辑、歌手、最近播放 |
| **歌词** | 滚动歌词、逐字歌词 |
| **首页** | 推荐、雷达 |
| **主题** | 封面取色、深色/浅色 |
| **桌面歌词** | 独立窗口、置顶、点击穿透（X11） |
| 播客 | 电台与节目 |
| 云盘 | 用户云盘歌曲 |

**里程碑**：`功能达到日常可用`

## 里程碑检查表

### 阶段 0 → 1 的准入条件

- [ ] gpui-kit 在三平台能构建出可运行应用
- [ ] libmpv 能播放音频（含 `stream-record`）
- [ ] 媒体控制在 KDE 与 GNOME 下均可用
- [ ] 托盘在 KDE Wayland 下点击有响应

### 阶段 1 → 2 的准入条件

- [ ] 能登录并播放网易云音乐
- [ ] 播放队列与模式切换正常
- [ ] 加密实现通过 Melodia 测试用例的等价验证

### 阶段 2 → 3 的准入条件

- [ ] 系统媒体键能控制播放
- [ ] 关闭窗口最小化到托盘
- [ ] 流式缓存可用（离线可听）

## 风险与应对

| 风险 | 阶段 | 应对 |
|---|---|---|
| gpui-kit 无法打包 | 0 | 尽早验证；备选 `iced` |
| libmpv 无 `stream-record` | 0 | 自写绑定；或牺牲该功能 |
| playwire 不满足 | 0 | 切 `zbus` 自研（有参照实现） |
| Wayland 托盘无响应 | 2 | 降级或依赖系统媒体键 |
| 加密实现偏差 | 1 | 用 Melodia 测试用例逐项校验 |
