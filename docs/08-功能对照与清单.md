## 1. 范围与方法

- **基准**：Melodia 桌面端实际功能（`desktopApp/` GUI + `shared/commonMain` 业务）。
- **对照对象**：Siren `crates/{siren-core,siren-platform,siren-app}`。
- **粒度**：到「一个可交付的用户能力」，而非单个文件。
- **标注图例**：

| 标记 | 含义 |
|---|---|
| ✅ | 已实现 |
| 🟡 | 部分实现 / 有待完善 |
| ⬜ | 未开始 |
| ⛔ | 非目标（Android 专属或明确不做） |

## 4. 建议里程碑（按依赖排序）

1. **核心播放闭环补全**：错误码映射 → 音质选择 → 喜欢/取消 → 歌曲详情 → 搜索多类型结果 → 播放记录上报 → 最近播放。（P0）
2. **歌词**：解析（LRC/QRC/TTML）+ 正在播放栏歌词视图（有 Melodia 测试用例可对照）。（P1）
3. **设置页** + 会话刷新/自动重登 + 系统媒体键开关。（P1）
4. **歌单/专辑写操作**：收藏、加歌到歌单、新建/删除/改名/改封面、曲目分页。（P1）
5. **音乐库扩展**：收藏列表、最近播放、歌单排序置顶；**个人主页 + 关注/粉丝**。（P1~P2）
6. **桌面平台（阶段 2 验收）**：托盘 + 单实例 + 关闭到托盘 + 面板拖拽调宽 + 上下文菜单。（P0）
7. **评论 / 播客 / 下载 / 云盘 / 本地音乐**。（P2）
8. **桌面歌词窗口 + 主题取色 + 队列面板 + 迷你播放器**。（P2~P3）

## 5. 非目标（⛔）

- 车机协议（`core/vehicle/LeapmotorProtocol.kt`）：Android 专属，桌面不做。
- 听歌识曲（`recognition`）：依赖移动端录音链路，桌面暂不做。
