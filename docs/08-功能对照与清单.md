## 1. 已完成（已开发功能）

### 1.1 核心 / 网络 / 认证

| 能力 | 说明 | 落点 |
|---|---|---|
| 加密 | WEAPI / EAPI / LinuxAPI（含对照测试） | `siren-core/src/crypto/` |
| HTTP 客户端 | reqwest + rustls、WEAPI/EAPI、Set-Cookie 提取 | `siren-core/src/network/client.rs` |
| 拦截器 / 设备 ID | 按端点选加密、设备指纹 | `network/interceptor.rs`、`network/device.rs` |
| 业务错误码映射 | `Error` 对齐 `AppError`（Network/RiskControl/Unauthorized/Parse/Biz）+ 响应 `validate` | `error.rs`、`network/api.rs` |
| 登录 | Cookie 登录 + **扫码登录**（二维码 PNG 生成 + 轮询） | `auth/`、`auth/qr.rs`、`ui/login_dialog.rs` |
| 会话 | 本地持久化 + 账号校验失败**自动续期**（`login/token/refresh`） | `auth/`、`ui/pages/library.rs` |

### 1.2 播放

| 能力 | 说明 | 落点 |
|---|---|---|
| 音频引擎 | 手写 libmpv FFI（libloading）+ Silent 降级 | `siren-core/src/player/mpv.rs` |
| 队列 / 模式 / seek / 音量 | 顺序·随机·单曲循环 | `player/queue.rs`、`ui/playback.rs` |
| 音质档位 | 8 档（标准~超清母带）+ 持久化 | `model/quality.rs`、`settings.rs` |
| 喜欢 / 取消喜欢 | 红心集合、乐观更新+回滚、播放条红心键 | `network/api.rs`、`ui/playback.rs` |
| 播放打卡上报 | weblog `startplay`/`play`（`os=osx` 伪装） | `network/api.rs`、`ui/playback.rs` |
| 歌曲详情 / 百科 / 制作人 / 回忆坐标 | `song/detail`、`play/about/block`、`song/creators` | `model/wiki.rs`、`network/api.rs` |
| 心动模式 / 相似漫游 | 智能推荐队列 / 相似歌曲建队列 | `network/api.rs`、`ui/playback.rs` |
| 系统媒体控制 | playwire（SMTC / MPRIS），可开关 | `siren-platform/src/media_session.rs` |

### 1.3 内容 / 页面

| 能力 | 说明 | 落点 |
|---|---|---|
| 首页 | 推荐歌单 | `ui/pages/home.rs` |
| 搜索 | 云搜索**多类型**（单曲/专辑/歌手/歌单）+ 真实封面 | `ui/pages/search.rs` |
| 歌单详情 | 表格（#/封面/标题·歌手/专辑/时长）+ 播放 | `ui/pages/playlist.rs` |
| 音乐库侧栏 | 我的歌单 + 登录入口 | `ui/pages/library.rs` |
| 最近播放 | 歌曲列表（真实封面） | `ui/pages/recent.rs` |
| 歌词 | LRC / YRC / QRC 解析 + 译文合并 + 当前行高亮视图 | `siren-core/src/lyrics/`、`ui/components/now_playing.rs` |
| 评论 | 列表 / 楼层 / 点赞 / 加载更多（浮层） | `network/api.rs`、`ui/components/comments.rs` |
| 歌手 | 详情 / 专辑 / 相似歌手 / 关注取关 | `model/mod.rs`、`ui/components/now_playing.rs` |
| 个人主页 / 最近播放入口 | 账号菜单跳转（个人主页为占位页） | `ui/components/title_bar.rs` |

### 1.4 正在播放栏（对齐 `NowPlayingPanel.kt`）

| 能力 | 说明 |
|---|---|
| 可滚动卡片堆叠 | 封面 → 标题/歌手 → 卡片流（非 tab） |
| 卡片 | 歌词预览 / 评论 / 歌曲详情 / 回忆坐标 / 关于歌手 / 歌手专辑 / 相似歌手 |
| 封面取色背景 | `CoverLoader` 提取主色作为面板底色 |
| 歌手专辑·相似歌手 | 横向分页 + 左右箭头（对齐 `ArtistListCards.kt`/`ScrollArrow.kt`） |
| 头部菜单 | 「…」→ 心动模式 / 相似歌曲漫游 |
| 卡片顺序·显隐 | 设置页可配置（持久化） |
| 宽度可调 | 300–800，持久化 |

### 1.5 桌面 / 设置

| 能力 | 说明 | 落点 |
|---|---|---|
| 窗口 | 无边框、自绘标题栏、拖动、最小化/最大化/关闭（`WindowControlArea`） | `ui/components/title_bar.rs` |
| 账号菜单 | 圆形头像、个人主页/最近播放/设置/退出 | 同上 |
| 设置页 | 音质 / 系统媒体键 / 右侧栏宽度 / 正在播放卡片 | `ui/pages/settings.rs` |
| 封面加载 | 尺寸分桶缓存 + 主色提取 + 圆形裁剪 | `ui/covers.rs` |
| 播放条 | shuffle/prev/play/next/repeat + 进度 + 音量 + 红心 + 真实封面 | `ui/components/player_bar.rs` |

## 3. 后续开发路线

> 按依赖与价值排序；每项给出 Melodia 参照源码，便于回溯。

### M4 · 歌单 / 专辑写操作（P1）
- [ ] 专辑详情 `getAlbumDetail` + 专辑页 —— `feature/playlist`
- [ ] 收藏/取消（歌单·专辑·歌手）`subscribe*` —— `PlaylistApi`
- [ ] 歌单增删歌曲 `manipulatePlaylistTracks`、新建歌单 `feature/create`
- [ ] 收藏歌曲到指定歌单 —— `domain/SongCollectDelegate.kt`、`TrackCollectMenu.kt`
- [ ] 改名/简介/封面、删除 —— `updatePlaylistName/Desc/Cover`、`deletePlaylist`
- [ ] 大歌单曲目分页 —— `domain/PlaylistTrackPaging.kt`

### M5 · 音乐库 / 账号扩展（P1~P2）
- [ ] 收藏的歌单/专辑、订阅歌手列表 —— `LibraryApi.getUserRecord/getAlbumSublist`
- [ ] 歌单排序 / 置顶 —— `UserPlaylistApi.updatePlaylistOrder/topPlaylist`
- [ ] 最近播放 歌单/专辑 + 按天分组 —— `feature/recent`
- [ ] 个人主页 + 关注/粉丝列表 —— `feature/profile`、`FollowListPage.kt`
- [ ] 账号设置（等级/VIP/绑定/改资料/签到/改头像）—— `feature/settings`

### M6 · 桌面平台（阶段 2 验收，P0）
- [ ] 托盘（图标/菜单/显示隐藏/关闭到托盘）—— `platform/native/*Tray*`、`ui/tray/`
- [ ] 单实例（唤起已有窗口）
- [ ] 面板拖拽调宽 —— `PaneResizeHandle.kt`
- [ ] 全局快捷键 / 开机自启 —— `GlobalHotkeyService.kt`、`AutoStartManager.kt`
- [ ] 上下文菜单 / 歌曲操作菜单 —— `DesktopMenu.kt`、`TrackActions.kt`
- [ ] 工具提示 / Toast —— `DesktopTooltip.kt`
- [ ] 系统强调色 / UI 缩放 —— `accent.rs`、`ui_scale.rs`

### M7 · 首页 / 发现（P1~P2）
- [ ] 首页板块化 / 每日推荐 / 排行榜 —— `feature/home`
- [ ] 曲风风格 —— `feature/music`
- [ ] 歌单分类 / 高质量歌单标签 —— `PlaylistCategoryViewModel`、`getHighQuality*`
- [ ] 搜索热榜 / 默认词 / 建议 / 历史 / 语音 —— `feature/search`

### M8 · 播放增强（P2）
- [ ] 无版权/VIP 自动换源（UNM / LX 插件 / 社区源）—— `core/source`
- [ ] 流式缓存（边听边存）+ 离线可播 —— `core/download`、`OfflinePlayability`
- [ ] 睡眠定时 / 跨淡入淡出 / 音效 —— `core/player/SleepTimer*`、`CrossfadePolicy`
- [ ] 桌面歌词窗口 —— `DesktopLyricBehavior.kt`
- [ ] 副歌时间段 —— `PlayerApi.getSongChorus`

### M9 · 评论扩展 / 播客 / 下载 / 云盘 / 本地（P2）
- [ ] 评论发表/回复（xeapi 写链路）—— `core/comment`
- [ ] 播客/电台 —— `feature/podcast`、`PodcastPages.kt`
- [ ] 下载（队列/记录/内嵌歌词/目录）—— `core/download`、`DownloadsPanel.kt`
- [ ] 云盘 —— `feature/cloud`、`CloudUploadApi`
- [ ] 本地音乐 —— `core/localmusic`

### M10 · 桌面体验完善（P2~P3）
- [ ] 主题取色 + 浅色主题 —— `ui/palette/*`、`ui/theme/vibrant/*`
- [ ] 播放队列面板（含拖拽排序）—— `PlayQueuePanel.kt`、`ReorderGestures.kt`
- [ ] 迷你播放器 / 全屏播放器 —— `FullPlayerTopBar.kt`
- [ ] 首页布局卡片编辑 / 动画 —— `CardLayoutEditor.kt`、`HomeLayoutAnimation.kt`
- [ ] 新碟上架 / 消息 / 听歌数据报告 / 内容过滤 —— `feature/newworks|message|listendata`、`ContentFilter.kt`
