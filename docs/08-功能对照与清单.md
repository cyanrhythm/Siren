## 0. 与 Melodia 桌面端的功能差距总览

> 基准：Melodia `desktopApp` 分支 `linux-desktop-develop`（最新），29,241 行 Kotlin，**16 条路由 / 11 个设置分组**。
> Siren 当前：**10 条路由 / 4 个设置分组**。以下为**逐项 grep 核实**后的"Melodia 有、Siren 无"清单。

### 0.1 整块业务模块缺失（Siren 完全没有）

| 业务模块 | Melodia 桌面端落点 | Siren 现状 |
|---|---|---|
| **播客/电台（完整页）** | `ui/podcast/`（订阅/榜单/分类/电台详情、`PodcastPages`、`RadioDetailPage`） | 🟡 仅首页"播客" tab + 播客卡片，**无详情/订阅/榜单/分类页** |
| **下载（队列/记录/内嵌歌词/目录）** | `ui/download/`、`data/download/DesktopSongDownloader` | ⬜ 仅 UI 有下载图标，**无下载器** |
| **云盘** | 设置页云盘入口 + `feature/cloud` | ⬜ 无（`cloud_search` 仅为云**搜索**，非云盘） |
| **LX 插件 / 换源** | `plugin/{GraalLxPluginRuntime,LxHostBridge}`、`ui/settings/LxPluginSection`、`core/source`（含 ZIP/7z 导入） | ⬜ 无（无换源、无插件、无 JS 运行时依赖） |
| **多平台聚合搜索** | `ui/search/PlatformTabs`（网易云 + 外部平台，下划线 Tab 切换） | ⬜ 仅单源（`cloud_search`） |
| **听歌数据报告** | `feature/listendata` | ⬜ 无 |

| 指标 | Melodia 桌面端 | Siren |

> Melodia 桌面端的领先项在**业务宽度**（约 6 个整块模块）与**桌面系统集成**（8 项能力）。
