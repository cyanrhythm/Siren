### G0 启动 / 窗口

- [ ] **G0.1 Linux 缺窗口系统实现（P0，2026-10-15 三轮复核）**：`linux/window_system.rs`（降级占位）。
  **历史**：原"非 Windows 窗口永不显示"结论有误（GPUI `Window::new` 无条件 `map_window()`，
  窗口正常显示）；守卫耦合已于 2026-10-15 全部解决——app 侧窗口操作改为**直接传窗口**
  （便捷函数接收 `HasWindowHandle`、句柄解析在平台实现中完成；异步场景用 GPUI
  `AnyWindowHandle` + `update`），`setup_tray` / 关闭保存 / 图标设置不再受 `if let Some(hwnd)` 阻挡，
  `hide_window` 返回是否生效供「关闭到托盘」正确降级；托盘已跨平台（根级 `tray.rs`）。
  **剩余**：Linux 窗口操作实现本身（显隐/几何/工作区/图标，待 X11/Wayland；
  X11 图标另可经 `WindowOptions.icon`）+ ksni 托盘在 KDE/GNOME 的实机验证
  （macOS 同构占位，随阶段 4）。→ 落点：补全 `linux/window_system.rs`。

### G1 播放链路问题族（P0）
