# 09 · 动效制作指南

> 面向 Siren 的 UI 动效开发。全部 API 均以本机依赖源码为准核验：
> `gpui-kit 0.7.3` → `gpui-base 0.7.3`（动效 DSL）→ `gpui-pre 0.3.9`（引擎，Zed GPUI 分支）。
>
> 结论先行：**GPUI 的动效底层能力完整**（弹簧、关键帧、序列、错峰、进出场、组合变换、CSS 级缓动），
> 足以做出复杂动效；代价是**偏命令式、需显式接入**，且 `div` 没有 CSS 式 `transform` 样式。

---

## 1. 能力分层

| 层 | crate | 提供 |
|---|---|---|
| 引擎 | `gpui-pre` | `Animation`（时长/循环/限帧）、物理弹簧 `SpringConfig`、`with_animation` 闭包驱动、内建缓动 |
| **动效系统** | `gpui-base::motion` | `Easing` / `Keyframes` / `Sequence` / `Stagger` / `Presence` / `MotionReveal` / `MotionTransform` / `transition()` / `spring()` / `animate_keyframes()` |
| 便捷 DSL | `gpui-base::animation` | `EffectTransition`（fade/slide/width/height 一行式组合）、`cubic_bezier` |
| 组件 | `gpui-component` | 已用上述 API 做出 shimmer / skeleton / spinner / sheet / tooltip / dialog 等成品动效 |

**导入方式**（沿用 Siren 现有风格）：

```rust
use gpui_kit::base::{
    Easing, Keyframe, Keyframes, Timing, Transition, Spring, SpringTarget,
    Stagger, StaggerOrigin, MotionStatus, MotionTransform, Presence,
    animate_keyframes, transition, spring, EffectTransition,
};
use gpui_kit::{div, px, App, ElementId, IntoElement, Window, Styled};
use std::time::Duration;
```

## 2. 三条核心路径（按使用场景选）

### 2.1 目标值过渡 `transition()` —— 最常用

给一个**目标值**，库自动从上一次采样值平滑过渡过去。适合 hover、选中、展开等"状态切换"。

```rust
// 在 render/绘制期调用；id 唯一标识这一个被过渡的值
let progress = transition(
    ("np-panel-width", self.id()),
    self.panel_open,          // 目标值（bool 实现了 Interpolate）
    Transition::new(Duration::from_millis(180))
        .ease(Easing::Custom(Rc::new(|t| t * t))),  // 或内置/自定义曲线
    window,
    cx,
);

div()
    .w(px(if progress { 360.0 } else { 240.0 }))
    .child(progress)
```

- 首个值**立即采用**，之后目标变化才过渡。
- 需要**反转不打断速度**（如拖动到一半反向）时用 `spring()` 而非 `transition()`。
- 需要状态时用 `transition_with_status()` 返回 `MotionValue { value, status }`。

### 2.2 物理弹簧 `spring()` —— 跟手 / Q 弹

适合会**在运动中被改变目标**的值——弹簧会保留速度，反向时自然减速掉头，而不是snap到新曲线的初速。

```rust
use gpui_kit::base::{spring, Spring, SpringTarget};

// T: SpringTarget（f32 / Pixels / Rems / bool / AnimationPhase）
let x: f32 = spring(
    "cover-slide",
    self.target_x,                                  // 目标（SpringTarget）
    Spring::new(Duration::from_millis(320))         // response：一次完整振荡周期
        .with_damping(0.8),                         // <1 过冲回弹，1 临界阻尼，>1 过阻尼；可校验版 try_with_damping
    window,
    cx,
);

div().left(px(x))
```

### 2.3 关键帧 `animate_keyframes()` —— 多段编排

适合入场/出场、脉冲、多阶段变化。

```rust
use gpui_kit::base::{Keyframe, Keyframes, Timing, Easing, animate_keyframes};

let frames = Keyframes::try_new([
    Keyframe::new(0.0, 0.0_f32).ease(Easing::Linear),
    Keyframe::new(0.6, 1.05),                       // 轻微过冲
    Keyframe::new(1.0, 1.0),
]).unwrap();                                        // 单帧/非单调/缺端点会 Err

let m = animate_keyframes(
    ("cover-enter", self.generation),               // ⚠️ 想重播就把 generation 放进 id
    &frames,
    Timing::new(Duration::from_millis(240)),
    window,
    cx,
);
div().opacity(m.value)                              // m.value: MotionValue<T>
```

**关键帧约束**（`Keyframes::try_new` 会校验）：至少 2 帧、offset 有限且落在 `0.0..=1.0`、offset 单调不减、首帧 offset=`0.0` 且末帧 offset=`1.0`。

## 3. 编排类工具

### 3.1 `Sequence` —— 多步序列
多步、逐步过渡的目标状态机（`Sequence::new(id, from).with_step(target, transition)`），
`sample(window, cx)` 返回 `SequenceSample`（含 `step()` / `is_finished()` / `status()`）。

### 3.2 `Stagger` —— 错峰延迟（列表逐项入场）
```rust
use gpui_kit::base::{Stagger, StaggerOrigin};

let stagger = Stagger::new(Duration::from_millis(20), StaggerOrigin::First);
// 也可用 Center / Last / Index(n) 作为扩散原点
for (i, item) in items.iter().enumerate() {
    let delay = stagger.delay(i, items.len());      // i 距原点的间隔
    let policy = Transition::new(Duration::from_millis(200)).delay(delay);
    let v = transition(("row", i), item.visible, policy, window, cx);
    // ...
}
```

### 3.3 `Presence` —— 进出场（挂载/卸载过渡）
`Presence::new(id, present).transition(t).sample(window, cx)` → `PresenceSample`，
含相位 `PresencePhase`（Enter/Exit），用于"元素消失时先播退场再真正移除"。

### 3.4 `MotionReveal` —— 测量式展开/折叠
先测量子元素高度，再按 `progress` 裁剪，带动画帧驱动。适合折叠面板、展开区。
```rust
MotionReveal::new("detail-reveal", progress, child.into_any_element())
```

### 3.5 `EffectTransition` —— 一行式组合（便捷）
```rust
use gpui_kit::base::{EffectTransition, ease_out_cubic};

EffectTransition::new(Duration::from_millis(150))
    .ease(ease_out_cubic)
    .slide_y(px(-4.0), px(0.0))
    .fade(0.0, 1.0)
    .apply(element, "tooltip-enter")        // 返回 AnimationElement
```
可链式叠加 `.slide_x/.width/.height/.fade/.slide_y`。

### 3.6 `NavStack` / `NavMotion` —— 页面转场
`gpui-base` 提供带转场的导航栈（`NavStack` / `NavPage` / `NavOperation` / `NavMotion`），
Siren 当前的自研路由（`ui/mod.rs` 的 `Route`）后续可考虑迁移以获得统一转场。

## 4. 底层直接驱动（需要完全控制时）

`gpui-pre` 的 `AnimationExt` 允许你把任意插值 `delta` 应用到任意样式。
`Animation` / `AnimationExt` / `pulsating_between` 由 `gpui-kit` 经其 prelude 通配导出（随 `use gpui_kit::*;` 引入）：

```rust
// Animation / AnimationExt / pulsating_between 来自 gpui-kit（经 use gpui_kit::*; 引入）
div()
    .with_animation(
        "pulse",
        Animation::new(Duration::from_millis(1200))
            .repeat()                                  // .repeat_synced() 相位锁全局时钟
            .with_easing(pulsating_between(0.6, 1.0))
            .with_max_fps(30.0),                       // 限帧省电
        |el, delta| el.opacity(delta),                 // delta ∈ 归一化时间
    )
```

要点：
- `Animation` 的 `easing` **输出不裁剪**，允许弹簧式过冲（>1）。
- `.repeat_synced()` 让多个动画共享同一时钟，避免相位漂移（多个 spinner 同时转）。
- **自动尊重 `App::reduce_motion`**：系统开启"减少动态效果"时，`oneshot` 动画直接渲染终态、循环动画渲染起始态。

## 5. 组合变换：`MotionTransform`（做缩放/旋转的关键）

`div` **没有** CSS 式 `transform` 样式（`Transformation` 只在 `svg` 元素上）。
需要缩放/旋转/位移/透明度的组合动效时，用 `MotionTransform`：

```rust
use gpui_kit::base::MotionTransform;
use gpui_kit::{point, px};

// 可在两个 MotionTransform 之间 interpolate（含 translation/scale/rotation/opacity）
let from = MotionTransform::identity();
let to = MotionTransform {
    translation: point(px(0.), px(-12.)),
    scale: point(0.96, 0.96),
    rotation_radians: 0.0,
    opacity: 0.0,
};
// 在自定义 Element 的 paint 中用窗口矩阵应用变换后绘制
```

> 若只是 `svg` 图标，可直接 `svg().with_transformation(Transformation::scale(...).rotate(...))`。

## 6. 缓动与插值

**内置缓动**（`gpui-base::animation` / `motion::easing`）：

| API | 说明 |
|---|---|
| `linear` / `quadratic` / `ease_in_cubic` / `ease_out_cubic` / `ease_in_out_cubic` | 基础曲线 |
| `ease_out_quint` | 强减速（入场常用） |
| `cubic_bezier(x1,y1,x2,y2)` | 自定义贝塞尔（返回结果可 `Err`） |
| `bounce(easing)` | 包裹式弹跳 |
| `pulsating_between(min,max)` | 往复脉动 |
| `Easing::steps(n, StepPosition)` | 步进（逐格跳变） |
| `Easing::linear_stops([...])` | 多段线性 |

**可插值类型**（`Lerp` / `Interpolate`）：`f32`、`Pixels`、`Point`、`Size`、`Bounds`、**`Hsla`（颜色）**，
以及 `bool`（离散）、`MotionTransform`。**自定义类型**实现 `Interpolate` 即可参与一切动效：

```rust
impl Interpolate for MyValue {
    fn interpolate(&self, target: &Self, progress: f32) -> Self { /* … */ }
}
```

## 7. 无障碍与性能（必须遵守）

1. **自动降级**：所有路径（`transition`/`spring`/`animate_keyframes`/`with_animation`）都会检查 `cx.reduce_motion()`，无需自行处理。自定义 Element 请同样检查。
2. **显式 opt-in**：base 组件**默认无动效**，注释原文 *"base components do not install default motion"*——要动效就得自己调。
3. **限帧**：非关键动画用 `.with_max_fps(f)`，减少无谓重绘。
4. **避免每帧 layout**：优先动画 `opacity`、位置、颜色、`MotionTransform`；改变 `w/h`/flex 会触发每帧布局，成本高。
5. **`id` 稳定性**：
   - `with_animation`/`transition`/`spring` 的状态以 `id` 为键；**同一个 id 重渲染不会重启动画**。
   - **要重播**动画，把"代次"编进 id，如 `("enter", generation)`。
   - `TransitionId` 支持多种来源：`&'static str` / `String` / `usize` / `i32`，或 `(id, "channel")` 元组（**一个元素内每种值类型需独立 channel**）。

## 8. 与 Melodia（Compose）对照

| 场景 | Melodia（Compose） | Siren（GPUI） |
|---|---|---|
| 状态过渡 | `animateFloatAsState` / `animateDpAsState` | `transition()` / `spring()` |
| 多关键帧 | `keyframes {}` | `Keyframes` + `animate_keyframes()` |
| 物理弹簧 | `spring(dampingRatio, stiffness)` | `Spring::new(response).damping(..)` |
| 列表错峰 | 手写 delay | `Stagger` |
| 进出场 | `AnimatedVisibility` | `Presence` / `MotionReveal` |
| 组合 transform | `graphicsLayer` | `MotionTransform`（自绘应用） |
| 缓动 | `FastOutSlowInEasing` 等 | `cubic_bezier` / `Easing::*` |

差异核心：Compose 是**声明式 modifier**（写个 `.animateContentSize()` 就有），GPUI 是**命令式闭包/自绘**（要自己算并 set）。`transition()`/`spring()`/`EffectTransition` 已把常见场景压到接近声明式的写法。

## 9. 建议的落地清单（针对 Siren 现状）

> 现状（已核验）：慢动效仍以**拖动重排**为起点接入，其余大部分为空白。已用 API 均为 `with_animation`
> （自动尊重 `reduce_motion`）。缓动曲线与时长集中在 `siren-app/src/ui/motion.rs`。

**已接入**：

| 位置 | 动效 | API |
|---|---|---|
| 播放队列拖动排序 | 拾起时跟随光标的**浮动预览**（淡入 + 轻微上浮，强 ease-out）；重排行 **FLIP** 从旧槽位平滑归位（强 ease-in-out） | `with_animation` / `Animation`（`ui/components/queue_panel.rs`） |
| 设置页卡片编辑器拖动排序 | 同款：浮动预览 + FLIP 归位 | `ui/pages/settings.rs` |
| 组件层（间接） | `Switch` 的滑块位移用 gpui-component 自带 `spring`（含中断反转） | `gpui_component::Switch` |
| 进度条刷新 | 墙钟插值 + ~60fps tick（非动效库，但为平滑进度） | `ui/playback.rs::tick` |

**待接入**：

| 位置 | 动效 | 推荐 API |
|---|---|---|
| 正在播放卡片流切换 | 淡入 + 上滑 | `EffectTransition` |
| 歌手专辑/相似歌手横向分页 | 平移动画 | `transition` + `Stagger` |
| 歌单/专辑封面上传替换 | 交叉淡入 | `transition`（颜色/透明度） |
| 列表首屏（首页/搜索/歌单） | 逐项错峰入场 | `Stagger` + `transition` |
| 评论浮层 / 正在播放面板展开 | 侧滑 + 淡入 | `EffectTransition` / `MotionReveal` |
| 网络请求骨架 | shimmer / skeleton | `gpui_component::shimmer` / `skeleton` 组件 |
| 页面切换（自研 Route） | 转场 | 迁移到 `NavStack`/`NavMotion` |
